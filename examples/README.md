# Examples

| file | purpose |
|---|---|
| `INSTALL.BAT` | slow-boot install with `.STK` backups; refuses a fast-boot tree |
| `AUTOEXEC.BAT` | serial mouse + start Windows |
| `WIN.INI.fragment` | `[windows] run=` and mouse section |

These are examples, not a complete DOS/Windows configuration. Adapt paths
and mouse settings to your machine.
